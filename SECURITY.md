# Security

Please don't report a security problem in a public issue. Use GitHub's private vulnerability reporting (the Security tab, then "Report a vulnerability"), or email [harin@runmyai.org](mailto:harin@runmyai.org) with the details and, if you can, the steps to reproduce it.

We'll get back to you as soon as we can.

A problem in the engine belongs to [TokenWing](https://github.com/runmyai/tokenwing/security).
