# Contributing to Run My AI

## Help with anything

Code, ideas, design, docs: improve or add whatever you'd like. Your own ideas are just as welcome. If they happen to fit where we're heading, that's a nice bonus.

**Where we're heading:**

- **The harness:** the part that turns a model into an assistant that gets work done. Light and minimal, with no personality by default, and packages you add for your own work.
- **Really good web search,** as the first step: reaching sites like Reddit, keeping you private, and ranking results well.
- **Better context management.**

## How a change gets in

Bug fixes and small changes can go straight to a pull request. For a new feature or a big change, open a short issue first.

- One topic per pull request.
- Fill in the pull request form: what changes, why, the impact (a screenshot for anything you can see), and how you tested it. Write n/a where a box doesn't apply.
- Run `flutter analyze` and `flutter test` first.
- Pull requests are squashed into one commit.
- You can use AI tools, as long as you understand every line you send.

Right now one person reviews everything, so a review can take a while and not everything can be accepted. Please don't take it personally.

By sending a pull request you agree that your work is under the [MIT licence](LICENSE).

[App design](docs/app-design.md) explains how the code is put together.

## Reporting a bug

Open an [issue](https://github.com/runmyai/run-my-ai/issues/new/choose) and fill in the bug form. Speed, memory and model output usually belong to the engine, but if you're not sure, report it here and we'll move it.

For a question or an idea, use [Discussions](https://github.com/runmyai/run-my-ai/discussions) or [Discord](https://discord.gg/BfpvUFp58).
